# Presentation of the plugin concepts

## Glossary

* Graphe : Un graphe orienté constitué d'un ensemble d'arcs et de noeuds
représentant le réseau des voies sous la forme d'un filaire de voies, correspondant à
l'axe de la chaussée.
* Axe : Une suite consécutive de tronçons formant une route / une voie (ex : RD115:.)
* Tronçon : Portion d'axe. Un tronçon est un segment orienté reliant deux noeuds (ligne simple)
* Noeud : Les nœuds représentent les sommets de début et de fin de chaque tronçon.
* Borne : Point créé par le gestionnaire des réseaux routiers qui est matérialisé
physiquement sur le terrain par des marques peintes associées à des bornes
kilométriques.
* Borne virtuelle : Point créé par l'administrateur SIG pour faciliter l'administration du
graphe et notamment des calcul de PR+abscisse
* PR : Points de repères (anciennement points kilométriques)
* Données métiers ou thématiques : Ensemble de données thématiques superposées
au graphe et topologique au graphe. Il s'agit de données ponctuelles (ex :
signalisation) ou de données linéaires (ex : revêtement).
