fix_graph_mark_as_bridge(_params jsonb)


Description

Action mark_as_bridge run by the function fix_graph_issue, to fix the issues of the check G01 when the edges must not be connected, for example on a bridge or in a tunnel.

It sets the field no_intersection_cutting to True for the edges passing by the crossing point: the given edge if the parameter _params contains edge_id, or else all the edges of edge_ids: {“point”: “SRID=2154;POINT(x y)”, “edge_ids”: [12, 34], “edge_id”: 12}.

It returns a JSON object with the keys status (success, or skipped if the edges are already marked) and message.
