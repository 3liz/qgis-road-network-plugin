refresh_graph_issues(_checks text[] DEFAULT NULL::text[], _road_codes text[] DEFAULT NULL::text[], _options jsonb DEFAULT NULL::jsonb)


Description

Run the checks of the road graph with the function check_graph, and update the issues stored in the table graph_issues of the editing session.

The parameters are the ones of check_graph: the checks to run and the road codes, all of them if NULL, and the options of the checks. Only the issues in the polygon of the editing session are stored: the issues of the edges copied beyond it cannot be fixed.

  • the stored issues found again keep their id and their fix status, their details and fix action are updated,
  • the stored issues of these checks and roads which are not found anymore are deleted,
  • the new issues are added.

It only works in the editing schema, with road_graph_editing.refresh_graph_issues. It returns the number of issues found.
