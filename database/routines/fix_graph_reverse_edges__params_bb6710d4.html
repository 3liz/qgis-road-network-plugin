fix_graph_reverse_edges(_params jsonb)


Description

Action reverse_edges run by the function fix_graph_issue, to fix the issues of the check G05: reverse the edges in the opposite direction of their road.

The parameter _params must contain the ids of the edges: {“edge_ids”: [12, 34]}. Only the edges still found by the check G05 are reversed, one by one: the triggers swap their start and end nodes, and calculate again their previous and next edges and the references of their road.

It returns a JSON object with the keys status (success, skipped if the edges are not in the opposite direction of their road anymore, or error) and message.
