get_editing_session_impacts(_editing_session_id integer)


Description

Get the impacts of the given editing session on the roads, to update only the managed objects which may be impacted. It must be run before the merge of the editing session, since it compares the production and editing data. It returns a JSON array with one object per impacted road: * road_code, * whole_road: true if all the objects of the road must be updated (references not calculated for the modified edges, for example for the roundabouts), * geometry_changed: false if the edges have only been split, or if only their attributes have changed, * start_marker_code & start_abscissa: the references of the first modified point, * end_marker_code: the last marker of the modified edges, * near_geom: the modified edges geometries, before and after the modifications, as hexadecimal EWKB, * marker_ranges: for each modified marker, the code of the previous marker and its code. The function get_managed_objects_impacts_filter uses this JSON to filter the managed objects to update.
