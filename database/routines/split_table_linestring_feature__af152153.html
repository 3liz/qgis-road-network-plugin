split_table_linestring_feature_by_point(_schema_name text, _table_name text, _feature_id integer, _point geometry)


Description

Splits a table linestring feature by a given point. The feature keeps the first part, and a new feature is created with the second part. If the table has the fields start_marker_code, start_abscissa, end_marker_code and end_abscissa, the references of the cut point become the end references of the feature and the start references of the new feature. The feature can be digitized in the direction of the road or in the opposite direction: the new geometries keep its direction.
