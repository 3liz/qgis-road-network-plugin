merge_edges(id_edge_a integer, id_edge_b integer)


Description

Merge two edges by their geometry. The merged edge is the one with the lowest id. The other edge is deleted. The node between the two edges is not deleted but its id is stored in the session variable ‘road.graph.merge.edges.useless.node’ for further use if needed.
