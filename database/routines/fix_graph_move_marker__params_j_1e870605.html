fix_graph_move_marker(_params jsonb)


Description

Action move_marker run by the function fix_graph_issue, to fix the issues of the check G09: move the first marker of a road to the start of the road.

The parameter _params must contain the ids of the marker and of the first edge of the road, and the start point of the edge as EWKT: {“marker_id”: 12, “edge_id”: 34, “point”: “SRID=2154;POINT(x y)”}. The marker is moved to the start point of the edge: the triggers calculate again the references of the road.

It returns a JSON object with the keys status (success, skipped if the marker does not exist anymore, is already at the start of the road, or if the edge does not start at the given point anymore) and message.
