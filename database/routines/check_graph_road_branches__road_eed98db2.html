check_graph_road_branches(_road_codes text[], _options jsonb)


Description

Check G06 run by the function check_graph: find the roads with branches, for example the ramps or the carriageways of a road using the code of the road.

An issue is returned for each node with more than two edges of the same road. The roundabouts are ignored, and the edges starting and ending at the same node. The main line of the road at the node is given by the edge arriving at the node and the edge leaving it which are the most aligned: the other edges are the branches. The details give the number of edges at the node, and the ids of the edges of the main line and of the branches. The line of the issue shows the branches.

The issue must be fixed manually, for example by giving another road code to the edges of the branches.
