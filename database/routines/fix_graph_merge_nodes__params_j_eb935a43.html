fix_graph_merge_nodes(_params jsonb)


Description

Action merge_nodes run by the function fix_graph_issue, to fix the issues of the check G03: merge two nodes close to each other.

The parameter _params must contain the ids of the node to keep and of the node to remove: {“keep_node_id”: 12, “remove_node_id”: 34}. The start and end points of the edges of the node to remove are moved to the node to keep, then the node to remove is deleted.

It returns a JSON object with the keys status (success, skipped if the node to remove does not exist anymore, or error if the nodes are linked by an edge) and message.
