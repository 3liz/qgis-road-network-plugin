check_graph_markers_order(_road_codes text[], _options jsonb)


Description

Check G10 run by the function check_graph: find the markers which are not in the order of their road.

The position of each marker along its road is the cumulative length of the road at its closest edge of the road, less than the option marker_tolerance from it (50 m by default). Sorted by code and abscissa, the markers must be in the order of their position: two markers can be at the same position (1 m tolerance). The longest sequence of markers in the order of the road is kept: an issue is returned for each other marker. The roundabouts are ignored. An issue is also returned for a marker far from its road, or whose closest edge has no reference.

The details give the type of issue (order, far_from_road or edge_without_reference), the code, abscissa, type and position of the marker, and the code and position of the previous and next markers in the order of the road. The issue must be fixed manually, by moving the marker or changing its code.
