get_managed_objects_impacts_filter(_geometry_type text, _table_cols text[], _geometry_column text)


Description

Build the SQL filter of the managed objects which may be impacted by the modifications of the road graph. The managed table must have the alias mo, and the impacts returned by the function get_editing_session_impacts must be given as the first parameter $1 of the query.
