fix_graph_issue(_fix_action text, _params jsonb)


Description

Fix an issue of the road graph found by the function check_graph, with the given action and parameters.

The issues must be fixed in an editing session: the function only works in the editing schema, with road_graph_editing.fix_graph_issue. It runs the function named fix_graph_ followed by the action name.

The issue may have been fixed by a previous action, for example when several issues concern the same edges: the action then does nothing and returns the status skipped. If the action fails, its changes are cancelled and the status error is returned with the error message.

It returns a JSON object with the keys status (success, skipped or error) and message.
