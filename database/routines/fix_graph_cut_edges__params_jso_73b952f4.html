fix_graph_cut_edges(_params jsonb)


Description

Action cut_edges run by the function fix_graph_issue, to fix the issues of the check G01: split the edges crossing each other at the given point.

The parameter _params must contain the crossing point as EWKT: {“point”: “SRID=2154;POINT(x y)”}. A node is created at this point, or the existing node less than 50 cm from it is used, and the triggers split the edges passing there.

It returns a JSON object with the keys status (success, or skipped if no edge must be split at this point) and message.
