clean_digitized_roundabout(_road_code text)


Description

Clean a roundabout digitized by QGIS circle tool: * delete the edges inside the roundabout, except the edges marked as not to be cut at the intersections (no_intersection_cutting), which are at another level, for example a road passing under the roundabout * remove the circle node added add 12 o’clock * add a marker for this roundabout if not already present

An exception is raised if the roundabout is not connected to any other road, for example when the edges crossing the circle are marked as not connected (no_intersection_cutting), and are therefore not cut by it.
