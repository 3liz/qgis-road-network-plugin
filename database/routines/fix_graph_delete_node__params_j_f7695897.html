fix_graph_delete_node(_params jsonb)


Description

Action delete_node run by the function fix_graph_issue, to fix the issues of the check G04: delete a useless node.

The parameter _params must contain the id of the node: {“node_id”: 12}. A node without edge is deleted. A node between two edges of the same road is deleted if one edge arrives at the node and the other one leaves it: the trigger before_node_delete merges the two edges into the edge with the lowest id. If the merged edge is not between the start node of the first edge and the end node of the second edge, for example because it has been split at a crossing with another edge, an exception is raised: the function fix_graph_issue cancels the changes and returns an error.

It returns a JSON object with the keys status (success, skipped if the node does not exist anymore or is not useless anymore, or error) and message.
