get_edge_references(_edge_id integer, _use_cache boolean DEFAULT false)


Description

Return the references of the given edge start and end point. Could be used to UPDATE the edges of a road. By default does not use road object cache store in a temporary table. This behaviour can be overriden by setting _use_cache TO True;
