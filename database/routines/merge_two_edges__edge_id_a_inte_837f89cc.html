merge_two_edges(_edge_id_a integer, _edge_id_b integer)


Description

Merge two edges of the same road following each other, used by the action Merge the 2 selected edges.

The edge with the lowest id is kept, and gets the geometry of the other edge (see merge_edges). The node between the edges is kept if it is used by other edges, for example a road starting on a bridge above the merged road: the merged edge is then marked as not to be cut at the intersections (no_intersection_cutting). An exception is raised if the edges do not exist, do not have the same road, or do not follow each other.

It returns the message describing the merge.
