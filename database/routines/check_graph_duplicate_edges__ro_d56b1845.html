check_graph_duplicate_edges(_road_codes text[], _options jsonb)


Description

Check G12 run by the function check_graph: find the duplicate edges, for example after a copy of an edge.

Two edges are duplicates when they have the same end nodes, in the same or the opposite direction, and the same geometry: their Hausdorff distance is less than the option tolerance (0.5 m by default).

An issue is returned for each kept edge, the edge with the lowest id, with its duplicates. The details give the kept edge, the duplicate edges, their road codes and the length of the kept edge.

The issue can be fixed with the action delete_duplicate_edges, which deletes the duplicates. The duplicates of another road have no fix action: they must be checked manually.
