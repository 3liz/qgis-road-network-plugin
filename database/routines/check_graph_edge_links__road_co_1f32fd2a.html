check_graph_edge_links(_road_codes text[], _options jsonb)


Description

Check G06 run by the function check_graph: find the edges whose previous or next edge contradicts the geometry.

The previous and next edges (fields previous_edge_id and next_edge_id) give the order of the edges of the road, used to calculate the references. The next edge of an edge is wrong when it does not start at the end node of the edge, whereas another edge of the road starts there, or when it is connected to another edge, or to the edge in the opposite direction. The previous edge is checked the same way. The other links, across a gap of the road, for example on both sides of a roundabout, are kept. The roundabouts are ignored. The expected link is the connected edge, or no link: a gap between two close nodes is fixed by the check G03.

An issue is returned for each road. The details give the number of edges and, for each edge, its previous and next edges and the expected ones. The issue can be fixed with the action relink_edges, which sets the expected previous and next edges of the road, then calculates again the references of the road.
